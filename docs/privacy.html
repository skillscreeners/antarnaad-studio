Privacy Policy

Last updated: 2 November 2026

This Privacy Policy applies to the "Antarnaad Studio Uploader" application (the "App"), an automation tool operated solely by its owner to publish the owner's own video content to the owner's own YouTube channel (Antarnaad Studio) and Instagram account.

Who uses this App

The App is used exclusively by its owner. It is not offered to, and is not intended to be used by, any other person. No third-party end users sign in to or interact with the App.

Data we access

The App uses the YouTube Data API and the Instagram Graph API only to upload videos and set their title, description, tags and privacy status on the owner's own accounts. It does not read, collect, store, sell, or share any personal data belonging to any other person. The App does not have a user base and does not process third-party personal information.

Credentials

OAuth tokens and API keys used by the App are stored as encrypted secrets in the owner's own GitHub Actions environment and are used only to authenticate uploads to the owner's own accounts. They are never shared with third parties.

Google user data

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to upload the owner's own content and is not transferred to others except as required to provide the upload functionality, or as required by law.

Data retention & deletion

The App stores no personal data. To revoke the App's access at any time, the owner can remove it from their Google Account permissions (myaccount.google.com/permissions) and from Instagram's Apps and Websites settings.
