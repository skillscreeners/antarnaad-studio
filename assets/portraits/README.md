# Portraits of quoted people (optional)

Put a photo here and every reel quoting that person uses it as the background.
Only add photos you have the right to use: your own, ones you licensed, or public-domain ones
(for example portraits published more than 60 years ago). No logos or watermarks.

File name = the person's name in lower case with dashes, .jpg or .png. Portrait (tall) photos work best.
